The goal of this project was to build a complete Machine Learning solution that can predict a student's final exam score using academic, behavioral, and personal factors. Instead of focusing only on model training, I followed the complete ML workflow—from data preparation to prediction—so that the project resembles a real-world machine learning pipeline

# Objective

The main objective of this project is to predict student performance using Machine Learning and understand which factors have the greatest impact on academic results.

The project covers:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Model Evaluation
- Model Comparison
- AI-powered Student Performance Prediction

---

# 📂 Dataset

To make this project realistic, I created a balanced dataset containing **250 student records**.

The dataset includes:

- Student_ID
- Gender
- Age
- Attendance
- Study Hours
- Assignment Score
- Previous Exam Score
- Participation Level
- Internet Access
- Extra Coaching
- Sleep Hours
- Screen Time
- Family Support
- Final Exam Score (Target)

The dataset was intentionally designed with:

- Realistic relationships between features
- Missing values
- Duplicate records

This allowed me to perform proper preprocessing before building the Machine Learning models.

# 🚀 Project Workflow

## 1. Data Collection

- Loaded the dataset
- Checked dataset structure
- Explored data types

---

## 2. Data Preprocessing

- Handled missing values
- Removed duplicate records
- Encoded categorical variables
- Selected useful features
- Applied StandardScaler for feature scaling

---

## 3. Exploratory Data Analysis (EDA)

To better understand the dataset, I performed:

- Descriptive Statistics
- Correlation Analysis
- Feature Importance Analysis
- Data Visualization

---

## 4. Machine Learning Models

I trained and compared the following regression algorithms:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- K-Nearest Neighbors (KNN) Regressor

---

## 5. Model Evaluation

The models were evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

After comparing the results, the best-performing model was selected for the final prediction system.

# 🤖 AI Prediction System

The final model is used to predict the final exam score of a new student based on the provided input values.

The prediction system displays:

- Predicted Final Exam Score
